# Contributing

Contributions are welcome.

1. Fork the repository.
2. Create a focused branch.
3. Add or update tests.
4. Run `ruff check .` and `pytest`.
5. If model behavior changes, run `python scripts/run_all.py`.
6. Commit refreshed metrics/figures with the code that produced them.
7. Open a pull request describing the scientific reason for the change.

Please do not silently replace the synthetic benchmark with a third-party dataset
whose redistribution license is unclear.
