# Data

The committed CSV files are reproducible synthetic benchmarks generated by:

```bash
python scripts/generate_data.py
```

They are included so the repository works immediately after cloning.

- `raw/urban_housing.csv`: synthetic residential sale-price benchmark.
- `raw/phishing_websites.csv`: synthetic phishing-detection benchmark.

These rows are not real people, websites, financial records or properties.
See `docs/DATASETS.md` for design details.
